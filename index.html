How It Works

Step 1: Open or Create

Launch TXT Write and open any TXT, code file, or PDF from Finder or iCloud Drive. Start fresh with a new document in your preferred format.

Step 2: Edit with Precision

Write plain text, code with real-time syntax highlighting, or annotate PDFs. Use freehand tools for diagrams, signatures, or markup.

Step 3: Sync and Preview

Edits sync automatically to iCloud. Preview HTML instantly; export any document as PDF for sharing or printing.

Step 4: Access Anywhere

Pick up exactly where you left off on iPhone or iPad. Handoff ensures continuity with Bluetooth and Wi-Fi enabled.

Does it support large files?

Yes, optimized for efficiency on macOS. Avoid very large PDFs in iCloud for best performance on mobile.

What formats are supported?

TXT read/write fully. Syntax highlighting for 15+ languages including HTML, JS, PHP, Ruby, Perl, Java, C/C++/Obj-C, and shell scripts.

Is iCloud required?

No—works offline with local files. iCloud enables sync and Handoff across devices.
